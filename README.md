# Gho Studio

Dashboard widyaiswara dengan tiga area: **Coach**, **Fasilitator**, dan **CMS** (Content Management System untuk media sosial), untuk Latsar, PKP, PKA, dan PKN Tingkat II.

| File | Isi |
| --- | --- |
| `SPESIFIKASI-GHO-STUDIO.md` | Spesifikasi lengkap (unggah ke Claude atau berikan ke programmer untuk membangun aplikasi) |
| `prototipe/gho-studio-prototipe.html` | Prototipe klik. Buka langsung di browser. Semua respon otomatis masih simulasi. |

Cara melihat prototipe: unduh file HTML, klik dua kali, lalu pakai tombol Coach, Fasilitator, CMS, Peserta di bilah atas.
